
SQL Injection

• Где ошибка: В методах выборки данных (например, поиск пользователей или товаров в WebGoat/Content/SQLInjection.aspx.cs), где входящие параметры из полей ввода вставляются в SQL-запросы к базе данных (MySQL / SQLite) через прямую интерполяцию строк вместо применения SqlCommand с параметрами.

Cross-Site Scripting (XSS)

• Где ошибка: В механизмах вывода комментариев и кастомного текста (например, WebGoat/Content/XSS.aspx.cs). Данные из запроса записываются в DOM-дерево или выводятся на страницу через свойства вроде Response.Write() или .Text без вызова методов очистки HttpUtility.HtmlEncode().

Missing Function Level Access Control

• Где ошибка: В административных контроллерах и каталогах (/Admin/). Конфигурационный файл web.config не содержит ограничений доступа <authorization> для директорий управления, а в коде страниц отсутствует проверка роли текущего пользователя (User.IsInRole("Admin")).

Insecure Direct Object References (IDOR)

• Где ошибка: В логике просмотра заказов и профилей (например, CustomerInfo.aspx.cs). Доступ к записям в БД выполняется на основе переданных клиентом параметров customerID или orderID без валидации совпадения идентификатора с текущим авторизованным пользователем сессии.

Weak Cryptography

• Где ошибка: В модулях авторизации и управления пользователями (Util/Encoder.cs). Пароли пользователей хэшируются с использованием устаревших и небезопасных алгоритмов (MD5 / SHA-1) без применения уникальной текстовой соли (Salt).
