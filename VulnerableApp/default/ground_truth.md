
JWT (JSON Web Tokens)

• Где ошибка: В модулях авторизации JWT. Используется небезопасный парсинг токенов, доверяющий алгоритму none, а также применение слабых статических ключей подписи.

Command Injection

• Где ошибка: В эндпоинтах утилиты выполнения системных команд ОС, где параметры пользовательского ввода передаются методам Runtime.getRuntime().exec() без предварительной очистки и фильтрации метасимволов.

File Upload Vulnerability

• Где ошибка: В обработчиках загрузки файлов на сервер. Отсутствует проверка расширения файлов (белого списка), типа контента (MIME-type) и валидация имени файла (риск Path Traversal при сохранении).

SQL Injection (SQLi)

• Где ошибка: В репозиториях работы с базой данных, где запросы строятся через прямую конкатенацию строк ("SELECT * FROM ... WHERE name = '" + input + "'") вместо использования PreparedStatement.

Path Traversal

• Где ошибка: В механизмах чтения файлов и локальных ресурсов. Входящие параметры путей не очищаются от относительных путей вида ../, позволяя выходить за пределы корневой папки приложения.

Cross-Site Scripting (XSS)

• Где ошибка: В контроллерах ответов. Пользовательский текст возвращается сервером и рендерится в браузере в неизмененном виде без HTML-экранирования.

XML External Entity (XXE)

• Где ошибка: В XML-парсерах (DocumentBuilderFactory), где по умолчанию не отключены директивы обработки внешних сущностей (External Entities) и кастомных DTD-схем.

SSRF (Server-Side Request Forgery)

• Где ошибка: В логике отправки исходящих HTTP-запросов со стороны сервера по ссылкам, предоставленным пользователем, без валидации целевых IP-адресов по белому списку (запросы к локальной сети или localhost).
