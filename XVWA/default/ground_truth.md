
SQL Injection (Error-Based / Blind)

• Где ошибка: В параметрах поисковых форм и фильтров товаров. Данные пользователя из массивов $_GET или $_POST конкатенируются напрямую в тело SQL-запросов без параметризации и экранирования.

OS Command Injection

• Где ошибка: В системных модулях (например, пинг хоста), где ввод пользователя передается напрямую в функции выполнения команд операционной системы (exec(), system(), shell_exec()) без фильтрации метасимволов командной строки (|, &, ;).

File Inclusion (LFI / RFI)

• Где ошибка: В параметрах переключения страниц (например, ?page=), где значения переменных подставляются напрямую в функции include(), require(), file_get_contents() без проверки путей и без ограничения белым списком файлов.

Cross-Site Scripting (Reflected / Stored / DOM)

• Где ошибка: В формах ввода данных (комментарии, формы поиска), откуда текст пользователя возвращается и рендерится в HTML-коде страницы браузера без вызова функций экранирования спецсимволов (htmlentities() или htmlspecialchars()).

Unrestricted File Upload

• Где ошибка: В форме загрузки файлов (например, аватаров), где отсутствует проверка расширения файла, его MIME-типа и запрет на исполнение скриптов в целевой директории, что позволяет загрузить сторонний .php файл.

Server-Side Request Forgery (SSRF)

• Где ошибка: В модулях, запрашивающих данные со сторонних ресурсов по ссылке от пользователя. Логика кода выполняет curl-запросы без проверки целевого IP-адреса, позволяя отправлять запросы в локальную сеть сервера (localhost).

PHP Object Injection

• Где ошибка: В механизмах обработки кастомных пользовательских данных, где строка из HTTP-запроса передается напрямую в функцию unserialize() без предварительной валидации структуры объекта.
