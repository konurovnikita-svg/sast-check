• API1 (BOLA / IDOR): В GET /books/v1/{title} нет проверки владельца. Можно читать чужие приватные книги.
• API2 (Broken Authentication): Секретный ключ для подписи JWT-токенов в коде — простое слово "secret". Токены легко подделать.
• API3 (Data Exposure): Эндпоинт /users/v1/_debug отдаёт JSON со всеми юзерами и их паролями в открытом виде.
• API4 (No Rate Limit): Нет ограничений на количество запросов. API уязвим к брутфорсу и DoS-атакам.
• API5 (Broken Function Authorization): Через PUT /users/v1/{username}/password можно менять пароль любого пользователя, просто подставив его имя в URL.
• API6 (Mass Assignment): При регистрации (POST /users/v1/register) можно передать скрытый параметр {"admin": true} и получить права администратора.
• API8 (Injection): Поля ввода не фильтруются. Через параметры пользователей можно провести SQL-инъекцию в базу SQLite.
• RegexDoS (Отказ в обслуживании): Плохое регулярное выражение для проверки email. Специальная строка намертво загружает процессор Python и вешает сервер.
