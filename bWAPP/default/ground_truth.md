
SQL Injection (HTML/Form & AJAX)

• Где ошибка: В файлах sqli_1.php, sqli_2.php и других модулях поиска/авторизации. Пользовательский ввод из массивов $_GET или $_POST конкатенируется напрямую в SQL-запросы без использования параметризованных запросов (PDO или bind_param).

OS Command Injection

• Где ошибка: В файле commandi.php. Вводимые пользователем IP-адреса для проверки сети передаются в системную функцию shell_exec() без предварительной очистки и фильтрации метасимволов командной строки (|, ;, &).

Remote / Local File Inclusion (RFI/LFI)

• Где ошибка: В файле rlfi.php. Значение параметра ?page= передается напрямую в функции include() или require() без валидации пути и сверки с белым списком разрешенных файлов.

Cross-Site Scripting (Reflected, Stored & DOM)

• Где ошибка: В файлах xss_reflected_raw.php, xss_stored_1.php и связанных модулях. Текст пользователя возвращается в HTTP-ответе и выводится на страницу без обработки функциями htmlspecialchars() или htmlentities().

Unrestricted File Upload

• Где ошибка: В файле unrestricted_file_upload.php. В скрипте загрузки файлов отсутствуют проверки расширения (белого списка), MIME-типа контента и валидация имени файла перед его сохранением в доступную для чтения директорию.

Server-Side Request Forgery (SSRF)

• Где ошибка: В модуле ssrf.php. Сервер принимает URL-адрес от клиента и выполняет к нему HTTP-запрос через библиотеку cURL без валидации протокола, порта и проверки целевого IP-адреса на принадлежность к локальной сети (127.0.0.1 / localhost).

XML External Entity Injection (XXE)

• Где ошибка: В файле xxe_1.php. Обработчик XML-данных использует функцию simplexml_load_string() или класс DOMDocument без явного отключения загрузки внешних сущностей через libxml_disable_entity_loader(true).

PHP Object Injection

• Где ошибка: В файле phpi.php. Данные из параметров HTTP-запроса (например, куки или POST-переменные) передаются напрямую во встроенную функцию unserialize() без проверки типа и структуры объекта.
